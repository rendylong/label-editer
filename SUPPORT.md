# Support

For installation help, bug reports, feature requests, and policy questions, use the [GitHub issue tracker](https://github.com/rendylong/label-editer/issues).

Before reporting a problem:

1. Start a new Codex session after installing or updating the Plugin.
2. Record the Plugin version, Codex version, Node.js version, operating system, and the command or workflow that failed.
3. Include the smallest reproducible example and the exact error text.
4. Remove secrets, tokenized editor URLs, customer data, proprietary GLB files, and other confidential content before posting.

Security-sensitive reports and reports that require private assets should not be posted publicly. Open a minimal issue asking for a private contact channel without including the sensitive details.
