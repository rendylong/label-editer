# GLB 贴标编辑器工作区重构设计规格

日期：2026-08-23  
状态：设计方向已确认，待规格评审  
范围：字体资源库、参数化几何元素、左侧工作区、右侧属性检查器、浅色视觉系统

## 1. 背景与目标

当前编辑器已经能够在 GLB 模型上创建贴标区域、进行 2D 排版、预览 3D 效果并导出结果，但编辑工作区存在四类相互关联的问题：

1. 字体仅以普通下拉框提供少量系统字体，跨设备、Canvas、3D 烘焙和导出的一致性不足。
2. 几何元素只有矩形，无法覆盖常见包装标签中的分割线、徽章、边框、装饰图形等设计需求。
3. 左侧把模型部件与贴标区域混合在同一棵树中，模型结构与标签设计结构缺少清晰边界。
4. 右侧同时承担 3D 预览、图层和属性编辑，空间拥挤，选择上下文与属性层级不清晰。

本次目标是将现有界面升级为以 2D 设计为主、以 3D 验证为辅的浅色专业编辑器，同时保持 2D 贴标区域严格遵循 3D 展面逻辑。

## 2. 设计原则

- 2D 是主要创作工作区，3D 用于实时验证和最终检查。
- 模型结构、贴标区域、图层结构使用不同的信息层级表达。
- 左侧负责导航与对象组织，中央负责创作与预览，右侧负责上下文属性。
- 高频操作直接可见，低频或高级参数按组折叠。
- 字体与几何元素必须具备可扩展的数据模型，不能继续通过独立硬编码按钮增长。
- 2D、3D、PNG、项目文件和 GLB 导出必须使用同一份设计数据。
- 保持专业软件的紧凑密度，不采用深色主题、过度圆角或大量悬浮卡片。

## 3. 方案选择

### 3.1 备选方案

#### 方案 A：继续扩展现有左右面板

优点是改动较小，缺点是模型、区域、图层和属性仍会继续竞争有限空间，无法从根本上解决信息架构问题。

#### 方案 B：模式化专业工作区（采用）

左侧分离“贴标”和“模型”，中央统一管理 2D/3D 视图，右侧只显示上下文属性。该方案在专业编辑体验、实现成本和现有架构兼容性之间最平衡。

#### 方案 C：完全可停靠面板

允许用户自由组合面板，但需要面板布局持久化、拖拽停靠与复杂响应式逻辑，超出当前产品阶段需要。

### 3.2 最终选择

采用方案 B，并使用浅色专业视觉体系。

## 4. 全局工作区架构

### 4.1 顶部工具栏

保留文件、项目、导入与导出等全局操作，并增加中央视图切换：

- `2D 设计`
- `2D + 3D`
- `3D 预览`

视图切换只改变中央工作区布局，不改变当前贴标区域、图层选择和属性上下文。

### 4.2 左侧导航

左侧使用两个清晰页签：

- `贴标`：进入设计模式后默认打开，管理贴标区域、元素添加和图层。
- `模型`：管理 GLB 部件搜索、层级、显隐、基础信息与创建贴标区域入口。

两个页签共享模型与区域状态，但不把两类结构混排在同一列表。

### 4.3 中央工作区

- `2D 设计`：最大化标签画布。
- `2D + 3D`：2D 为主视图，3D 为可调整大小的辅助预览。
- `3D 预览`：用于正式视觉检查，隐藏编辑辅助标记。

中央视图需维持相同的选择状态，3D 预览不再占用右侧属性栏空间。

### 4.4 右侧检查器

右侧只显示当前上下文的属性：

- 选中文字时显示文字属性。
- 选中图形时显示图形属性。
- 选中图片时显示图片属性。
- 多选时显示公共变换、对齐和分布操作。
- 未选择图层时显示标签纸张、贴标区域和全局工艺。
- 在模型页签选中未创建贴标区域的网格时，显示部件摘要和创建入口。

## 5. 左侧贴标工作区

### 5.1 信息顺序

贴标页签从上到下包含：

1. 当前贴标区域选择器。
2. `添加元素`主操作。
3. 图层列表。
4. 图层快捷操作栏。

当存在多个贴标区域时，区域选择器显示区域名称、目标部件名称和区域状态。区域的新增、重命名与删除通过区域菜单完成，不与图层操作混淆。

### 5.2 图层列表

每个图层行显示：

- 类型图标。
- 可读名称或文字摘要。
- 工艺状态标记。
- 显隐与锁定状态。

复制、删除、前后移动等低频操作放在行菜单或底部快捷栏，减少每行持续显示的按钮数量。图层顺序支持拖拽，并继续写入 `zIndex`。

### 5.3 模型页签

模型页签单独提供：

- 部件名称搜索。
- 层级树。
- 显隐操作。
- 网格、材质、三角形数量摘要。
- 已绑定贴标区域标记。
- 对未绑定网格创建贴标区域的明确入口。

选择普通模型部件不应打断当前贴标设计，只有用户明确切换区域或进入创建流程时才改变设计上下文。

## 6. 元素资源库

### 6.1 打开方式

点击左侧 `添加元素` 打开锚定于左栏的元素资源库。资源库不是永久占据右侧的属性面板。添加元素后关闭或保持打开由最近一次用户选择记忆。

### 6.2 分类

首批分类与元素：

#### 文字

- 标题文字
- 正文文字
- 竖排文字
- 弧形文字（若首期实现成本过高，可作为同一数据模型的下一阶段能力，不以旋转单字模拟）

#### 基础图形

- 矩形
- 圆角矩形
- 圆形
- 椭圆
- 三角形
- 菱形
- 多边形
- 星形

#### 线条

- 直线
- 虚线
- 双线
- 箭头
- 波浪线
- 弧线

#### 标签组件

- 胶囊框
- 圆形徽章
- 方形徽章
- 爆炸贴
- 价格签
- 角标

#### 装饰元素

- 十字
- 括号
- 分割符
- 圆点阵列
- 放射线
- 边角装饰

#### 容器

- 外边框
- 内容底板
- 色块区域

### 6.3 参数化几何模型

现有 `ShapeLayer.shape = 'rectangle'` 将升级为可扩展的判别联合类型。公共属性包括：

- `width`、`height`
- `fill`、`stroke`、`strokeWidth`
- `opacity`
- `cornerRadius`
- `dash`
- `x`、`y`、`rotation`
- `visible`、`locked`、`zIndex`
- `craft`

特定图形使用 `geometry` 参数承载，例如：

- 多边形：边数。
- 星形：尖角数、内外半径比例。
- 线条：端点、箭头类型、虚线模式。
- 波浪线：振幅、频率。
- 爆炸贴：尖角数、随机度或内外半径比例。

预置元素只提供初始化参数；添加后仍是完全可编辑的原生图层，不烘焙为图片。

## 7. 字体资源库

### 7.1 规模与分类

首批目标约 60 款开源字体：

- 中文字体约 12 款。
- 现代无衬线字体约 16 款。
- 衬线与品牌风格字体约 12 款。
- 窄体与标题字体约 10 款。
- 手写与装饰字体约 6 款。
- 等宽字体约 4 款。

字体清单使用独立 manifest 管理，包含稳定 id、显示名称、family、分类、语言覆盖、字重、样式、资源地址与授权信息。

### 7.2 字体浏览器

字体选择不再使用原生下拉框。点击字体字段后打开字体浏览器，提供：

- 名称搜索。
- 分类筛选。
- 当前文字的实际字体预览。
- 收藏字体。
- 最近使用字体。
- 字重与斜体支持状态。
- 中文、拉丁文和数字覆盖提示。
- 加载中、加载失败和回退状态。

### 7.3 加载与导出一致性

- 字体资源随应用部署，但按需加载，不在首次启动时全部解析。
- 中文字体允许使用分包或按字形子集策略控制体积。
- 应用在字体 `FontFace` 就绪后再刷新 Canvas 和 3D 烘焙纹理。
- PNG、GLB 和项目导出前必须等待当前使用字体完成加载。
- 项目文件保存字体稳定 id、字重和样式；用户上传字体继续保存项目级记录。
- 字体不可用时显示明确警告，并使用确定性回退，不静默改变设计。

### 7.4 兼容策略

旧项目中的字体显示名称通过迁移映射到新的字体 id。无法映射的名称保留并进入系统字体回退流程，不能阻止项目打开。

## 8. 右侧属性检查器

### 8.1 通用结构

检查器顶部固定显示：

- 当前对象类型与名称。
- 显隐、锁定和删除等对象级操作。

属性按以下顺序组织为可折叠分组：

1. 内容。
2. 排版或几何。
3. 位置与尺寸。
4. 外观。
5. 工艺。
6. 高级设置。

高频分组默认展开，高级分组默认折叠。分组展开状态按对象类型记忆。

### 8.2 文字属性

- 文本内容。
- 字体浏览器入口。
- 字重、斜体、字号。
- 行高、字距、对齐。
- 横排、竖排及后续弧形排版入口。
- 颜色、不透明度与工艺。

### 8.3 图形属性

- 图形类型和特定几何参数。
- 宽高及比例锁定。
- 填充与描边。
- 圆角、虚线和线端。
- 不透明度与工艺。

### 8.4 图片属性

- 原始尺寸与当前尺寸。
- 比例锁定。
- 适应、填充和裁切方式。
- 不透明度与工艺。

### 8.5 变换与多选

统一变换模块提供：

- X、Y、宽、高、旋转。
- 比例锁定。
- 键盘方向键微调。
- 多选对齐、分布和等间距。

画布选择、图层选择和检查器状态必须双向同步。

### 8.6 标签与区域属性

未选择图层时显示：

- 标签纸张开关、颜色和不透明度。
- 贴标区域摘要。
- 进入 2D 展开图编辑区域的入口。
- 全局工艺。

默认纸张继续保持透明，不重新引入默认白底。

## 9. 浅色视觉系统

### 9.1 基础色

- 应用背景：`#F4F6F8`
- 面板背景：`#FFFFFF`
- 画布工作区：`#EEF1F4`
- 主文字：`#20242C`
- 次级文字：`#667085`
- 弱化文字：`#98A2B3`
- 边框：`#E4E7EC`
- 强调色：`#356AE6`
- 强调悬停：`#2859C5`
- 选中背景：`#EAF1FF`
- 危险色：`#D92D20`
- 成功色：`#178A50`

### 9.2 视觉规则

- 不提供深色作为默认界面，本次实现以浅色主题为唯一设计基线。
- 不使用装饰性渐变。
- 阴影仅用于弹层、菜单和拖拽浮层。
- 主要面板通过背景与细分隔线建立层级，不做大量卡片嵌套。
- 圆角保持克制，表单和按钮使用中小圆角。
- 3D 场景使用浅色摄影棚背景，并确保白色模型仍能通过轮廓、接触阴影和环境光清晰辨识。
- 透明标签画布使用浅色棋盘格，不能误导为实体白底。

### 9.3 交互状态

- Hover、focus、selected、disabled 与 error 状态均需独立可辨识。
- 键盘焦点使用明确的强调色描边。
- 动画只使用 `transform` 与 `opacity`，并尊重减少动态效果设置。

## 10. 状态、撤销与项目格式

- 新增字体、图形、属性折叠和视图模式所需状态应按作用域分离：项目状态、区域状态、图层状态与纯 UI 状态不能混用。
- 所有会改变设计输出的操作进入区域撤销栈。
- 纯 UI 状态，如页签、折叠状态、字体搜索和视图模式，不进入设计撤销栈。
- 项目格式增加版本迁移，保证旧矩形图层、旧字体名称和旧 `.lbl` 项目可以继续打开。
- 不允许将图形预置的 UI 名称作为渲染逻辑的唯一数据源。

## 11. 错误处理

- 字体加载失败：保留对象选择和编辑能力，显示回退字体及导出阻断提示。
- 字体缺字：在字体字段显示覆盖警告，但允许用户继续设计。
- 不支持的旧图形参数：使用最接近的安全默认值并记录迁移警告。
- 3D 烘焙失败：保留 2D 设计状态，显示可重试错误，不重置图层。
- 无活动贴标区域：元素添加操作禁用，并引导用户到模型页签创建区域。

## 12. 验证与验收

### 12.1 单元与集成验证

- 字体 manifest、字体 id 解析与旧字体迁移。
- 字体加载、失败回退及导出等待。
- 每类参数化图形的创建、修改、序列化与反序列化。
- 旧矩形图层兼容。
- 左侧页签与选择状态同步。
- 右侧检查器上下文切换。
- 视图切换不丢失选择和编辑状态。
- 撤销与重做覆盖字体、图形和属性修改。

### 12.2 E2E 流程

1. 打开 GLB。
2. 在模型页签创建或选择贴标区域。
3. 回到贴标页签。
4. 从元素库添加文字、字体、图形与图片。
5. 使用检查器修改排版、几何、位置、外观和工艺。
6. 切换 2D、分屏和 3D 视图。
7. 保存并重新打开项目。
8. 导出 PNG 与 GLB。
9. 对比 2D、3D 和导出结果。

### 12.3 视觉检查

- 1280×720、1440×900、1920×1080 三种常用桌面尺寸。
- 左侧区域和图层不混入模型部件。
- 右侧属性在长内容情况下可滚动且固定标题不丢失。
- 字体浏览器和元素库不超出视口。
- 浅色 3D 场景中白色、透明和深色模型均有足够轮廓。
- 无默认白色标签背景回归。

## 13. 非目标与后续扩展

本次不包含：

- 自由停靠和拖拽重组全部面板。
- 在线字体商店或付费字体授权系统。
- 完整矢量路径钢笔工具。
- 任意 SVG 节点级编辑。
- 多人协同编辑。

数据模型需为后续弧形文字、SVG 导入、组合与蒙版能力保留扩展空间，但不能以未完成的占位按钮冒充已交付能力。

## 14. 验收结论

本设计在以下条件全部满足时视为完成：

- 首批约 60 款可搜索、可预览、按需加载的字体资源可用。
- 常用贴标几何元素通过统一参数化模型创建和编辑。
- 左侧模型与贴标工作区完全分离。
- 右侧成为稳定的上下文属性检查器。
- 2D/3D 视图从属性栏解耦，切换不丢失设计状态。
- 整体采用已确认的浅色专业视觉体系。
- 旧项目兼容，自动化测试、构建、E2E 与视觉检查通过。
